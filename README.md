## Product direction

CAB starts at the player's real GPS location and uses real map locations as the game world. Progression opens regional, national and international metropolitan contracts; at maximum level the World License unlocks free worldwide location choice.

The physical world remains real. Passengers, dialogue, humour, personal stories and procedural mission events provide the fiction.
